# 17 — Partner program rules (E11 beachhead)

**Statut :** ACTIVE — rules document ; runtime partner registry reste E11 code.

## Admission

1. Demande écrite + KYC light marché beachhead.
2. Territory request non exclusif par défaut (conflict review).
3. Commission plan Edge créé **avant** premier deal enregistré.
4. Calc commission ≠ payout (voir `commission-payout-boundary`).

## Territory / conflict

| Règle | Comportement |
|-------|--------------|
| Opportunity registration | Obligatoire avant quote partenaire |
| Conflict window | 30 jours ; Edge SoT registration timestamp |
| Direct vs partner | Account plan ABM Enterprise prime si flag Enterprise |

## Commission

- Plan + rules immutables après activation.
- Calculation snapshot keyed ; re-calc = new key.
- Approve SoD ≠ calculate actor.
- Payout = workflow treasury séparé ; jamais auto depuis approve.

## Anti-patterns

- Silent entitlement bump pour deals partner.
- Payout sans APPROVED calculation.
- Territory exclusive inventée sans policy record.
