# 18 — Enterprise ABM templates (E11 beachhead)

## Account list fields (minimum)

- Account name / legal entity
- Segment (Pharmacy / Wholesale / Restaurant / Other)
- Tier target (Enterprise)
- Owner (CS + Sales)
- Health band (from E9) + churn risk
- Open opportunities / renewals

## Account plan (one page)

1. Business outcomes (hypothèses explicites — pas de ROI inventé)
2. Stakeholders map
3. Expansion signals observés (quote path only)
4. Risks (delinquency, low Aha, support load)
5. Next commercial action + date

## Enterprise assessment checklist

- [ ] Multi-site / multi-org model compris (same product tenant)
- [ ] Entitlement grants explicites
- [ ] Integration / Keycloak requirements
- [ ] Billing cadence + setup fees
- [ ] DPA / security questionnaire status
- [ ] Customization governance: no silent fork of BB without Edge grant

## Business case template

| Hypothèse | Source | Qualité |
|-----------|--------|---------|
| Sites / users | Customer declared | ESTIMATED until MEASURED |
| ARPU | Commercial catalog | MEASURED price book |
| Expansion | Usage signals | Recommendation only |
| Payback | Finance | UNAVAILABLE if costs missing |

Never present UNAVAILABLE payback as 0.
