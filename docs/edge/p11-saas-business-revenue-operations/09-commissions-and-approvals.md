# 09 — Commissions & approvals

## In scope (MVP)

- Create commission plan (+ optional rules)
- Calculate **immutable** commission snapshot (`calculation_key` unique)
- Read placeholder for plan list (PARTIAL — no fabricated totals)

## Out of scope / deferred

- Full approval queue UI
- Accrual→payment bridge (would violate P11 no-payment rule)

Permissions: `platform:commission:read|calculate|approve`.
