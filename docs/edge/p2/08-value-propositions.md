# Value propositions

Linked to product + vertical; optional segment/ICP.

## Governance
Quantitative outcomes containing `%` **require** non-empty `evidence` provenance. Invented ROI percentages are rejected at the use-case layer.

## API
- `GET/POST /api/v1/edge/commercial/value-propositions`
- Permission: `platform:commercial:value_props:manage`

Default `validation_status = UNVALIDATED`.
