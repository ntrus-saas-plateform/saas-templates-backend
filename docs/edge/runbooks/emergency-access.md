# Runbook — Emergency (break-glass) access

## Policy
- Temporary, scoped, justified, audited.
- Never converts into a permanent role assignment.
- Requester cannot approve their own request when SoD applies.

## Procedure
1. Request via Edge security API with scope + duration + justification.
2. Independent approval when required.
3. Activate; monitor privileged actions.
4. Auto-expire or revoke; verify audit trail complete.
