# P7.0.7 — Workflow Engine Decision Analysis

**Date:** 2026-11-10  
**ADR:** ADR-P7-002 — Status **PROPOSED** (not ACCEPTED until human approval)

## Options

| Option | Pros | Cons | Fit |
|--------|------|------|-----|
| A. Elevate JobScheduler | Already present | No leases/fencing/compensation/history | Reject |
| B. Reuse Identity TenantProvisioningOrchestrator | Step resume exists | Wrong BC; no compensation; ERP tenants | Reject as SoT |
| C. Internal durable engine in Edge CP | Fits Nest/Postgres/outbox; full control | Must build | **Recommended** |
| D. Temporal/Cadence | Mature durability | New ops surface, learning, not in stack | Defer |

## Criteria scores (C recommended)

Durability, recovery, compensation, observability, stack fit, maintenance — C wins for reference path.

## Decision (PROPOSED)

Build internal durable workflow engine; scheduler only for recovery polls; Identity orchestrator remains ERP-only.
