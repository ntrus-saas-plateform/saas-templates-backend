## Finding P7-KEYCLOAK-SEC-001

**Domain:** Identity Topology  
**Observed:** Single admin realm resolver + org APIs; no product topology isolation layer.  
**Expected:** Explicit realm/org/client bindings + issuer/audience checks per product tenant.  
**Class:** BUILD  
**Risk:** P0  
**Confidence:** HIGH  

## Finding P7-KEYCLOAK-SEC-002

**Domain:** Admin privilege  
**Observed:** Keycloak admin client_credentials for org/user ops; realm create only in import script.  
**Expected:** Least-privilege service accounts per environment; no workflow calling import script.  
**Class:** EXTEND  
**Risk:** P1
