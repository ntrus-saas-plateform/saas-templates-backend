### Architecture claim evaluation

| Claim | Evidence | Conclusion |
|-------|----------|------------|
| Modular monolith | Single Nest app; modules `edge`, `identity`, `platform` | **Verified** |
| Hexagonal (ports/adapters) | `domain` / `application` / `infrastructure` / `presentation` under Edge; Symbol ports | **Verified** (pattern applied; not every domain equally pure) |
| DDD | Aggregates/entities in domain folders | **Partially verified** |
| CQRS | Not systematic command/query split | **Not verified as CQRS system** |
| Event-driven | Outbox → RabbitMQ → handlers | **Verified** for Edge coordination |
| Microservices | One deployable `platform` service in compose | **Not microservices** |
