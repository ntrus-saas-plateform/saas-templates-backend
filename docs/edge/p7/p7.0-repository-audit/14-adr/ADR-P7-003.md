# ADR-P7-003 — Product Control Contract

**Status:** PROPOSED  
**Date:** 2026-11-10

## Decision
Versioned Product Control Contract (discovery, provision, IAM prep, config, entitlements, readiness, activation, lifecycle, M2M, idempotency, errors). Metadata tables alone insufficient.

## Consequence
Reference mock BB until real BB repos onboarded; contract tests mandatory.
