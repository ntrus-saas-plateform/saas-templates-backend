# ADR-P7-004 — Keycloak Topology Strategy

**Status:** PROPOSED (BLOCKED for production Mode claims until live version VERIFY)  
**Date:** 2026-11-10

## Decision
Support Modes A–D via explicit topology mode. SaaS reference = Mode B (shared realm + orgs). Separate product bindings from Edge vertical / Identity orgs. Mode A requires controlled createRealm adapter (not import script).

## Evidence
KC image 26.0 + Organizations; org APIs in admin client; createRealm only in `scripts/import-keycloak-realm.ts`; live runtime UNVERIFIED this host.
