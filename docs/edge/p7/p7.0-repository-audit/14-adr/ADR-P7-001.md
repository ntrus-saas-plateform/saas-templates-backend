# ADR-P7-001 — Provisioning Control Architecture

**Status:** PROPOSED  
**Date:** 2026-11-10

## Context
P7 needs a control system for authorization→placement→workflow→adapters without owning BB business logic.

## Options
1. New microservice  
2. Edge modular domains in existing Nest monolith  
3. Extend Identity Platform admin  

## Decision
**Option 2** — Provisioning Control as Edge domains inside `saas-templates-backend`.

## Consequences
+ Reuses RBAC, outbox, migrations, deploy  
− Must enforce strict BC boundaries vs Identity  

## Rejected
Microservices (premature); Identity admin path (wrong tenant model).

## Approval
Requires architecture owner ACK before ACCEPTED.
