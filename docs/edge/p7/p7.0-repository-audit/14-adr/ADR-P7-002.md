# ADR-P7-002 — Durable Workflow Engine

**Status:** PROPOSED  
**Date:** 2026-11-10

## Decision
Build **internal durable workflow engine** (Postgres definitions/instances/steps/leases/fencing/compensation). JobScheduler = recovery polls only. Temporal deferred.

## Evidence
No leases/fencing today; Identity orchestrator wrong BC; JobScheduler interval+Redis lock only.

## Gate
G4: crash recovery without duplicate side effects.
