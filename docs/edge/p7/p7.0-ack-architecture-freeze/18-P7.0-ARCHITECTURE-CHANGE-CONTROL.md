# 18 — Architecture Change Control

| Document ID | P7.0-ACK-18 | Version | 1.0.0 | Date | 2026-11-10 |

## Rule

Frozen baseline `1.0.0-freeze` may change only via documented Architecture Change Request (ACR).

## ACR minimum content

1. Change ID & requester  
2. Frozen items affected (principles, ADRs, contracts, graphs, backlog scope)  
3. Problem / driver  
4. Options & recommendation  
5. Impact on security, tenancy, P5/P6 boundaries, workflow, KC, BB  
6. Migration / compatibility  
7. Test & rollback plan  
8. Approvers (same roles as sign-off)  

## Approval

- Editorial clarifications: Engineering Lead  
- Boundary / security / tenancy changes: Security + Domain + Product  
- Expanding P7.1 authorized scope: new ACK delta document  

## Forbidden

Silent deviation in code from frozen invariants (especially Identity≠product tenant; P6≠activation; fail-closed auth).
