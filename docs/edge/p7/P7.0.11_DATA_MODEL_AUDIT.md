## Missing P7 schemas (BUILD sequence)

1. Provisioning authorizations & requests (richer than 089)  
2. Product platform / runtime environment registries  
3. Placement & capacity  
4. Workflow definitions/instances/steps/attempts/leases  
5. Infrastructure / DB bindings  
6. Identity topology bindings & establishment mappings  
7. Config/entitlement deployment records  
8. Lifecycle operations  
9. Onboarding cases  
10. Reconciliation runs  
11. Connectivity agents  

## Principles

- Do not overload `tenants` (Identity) for product tenants  
- Preserve P5 `correlation_id` uniqueness semantics  
- Prefer link from new P7 request → 089 coordination row over destructive rewrite  
- Keycloak ids are technical refs only  
- Migrations accompany each sub-phase with rollback/forward-fix notes
