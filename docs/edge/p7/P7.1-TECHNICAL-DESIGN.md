# P7.1 — Technical Design

| Version | 1.0.0 |
| Date | 2026-11-10 |

## Domain

- **Authorization** (P5-issued, P7-verified) ≠ **Request** (P7 durable) ≠ **Workflow** (P7.4 out of scope)
- States: `REQUESTED | ACCEPTED | REJECTED | CANCELLED | FAILED` — never `ACTIVE`/`PROVISIONING`/`READY`
- Uniqueness: `(authorization_id, operation, authorization_version)` + `idempotency_key`

## Trust (OQ-01 Option C)

S2S + canonical digest (SHA-256) + asymmetric signature (EdDSA/ES256/RS256). Digest-only rejected. Audience `okapi.edge.p7`.

## Sync revoke (OQ-04)

Before accept: `P5AuthorizationStatusPort` with timeout **2s**; timeout/unavailable/unknown → reject.

## Feature flag (C-02)

`EDGE_P7_PROVISIONING_ADAPTER=unavailable|durable` — default unavailable.

## API

`GET/POST /api/v1/edge/provisioning-requests…` with permissions `platform:provisioning_requests:*`.

## ERD (logical)

```
edge_provisioning_authorizations 1──* edge_p7_provisioning_requests
edge_p7_provisioning_requests 1──* edge_p7_provisioning_request_history
edge_p7_authorization_revocation_inbox (dedup by event_id / auth+version)
```
