## Executive summary

Okapi Edge today is a Nest modular monolith (`saas-templates-backend`) plus Next.js Edge console (`saas-template-frontend`) with **P0–P6 implemented to varying completeness**. Product-tenant provisioning (P7) is **not implemented**: P5 exposes an honest **UNAVAILABLE** provisioning port and coordination table; Identity/Platform provide an ERP tenant saga that **must not** be reused as product SoT.

Keycloak is declared as **26.0** with Organizations enabled; **live build was not verified** on this host (port 8080 ≠ Keycloak). No separate Business Backend repository exists in the workspace.
