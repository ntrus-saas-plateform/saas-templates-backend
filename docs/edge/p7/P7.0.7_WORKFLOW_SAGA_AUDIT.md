## Decision input (feeds ADR-P7-002)

**Recommendation:** Build **internal durable workflow engine** in Edge CP DB (modular monolith), reuse outbox + scheduler for recovery polls. Do **not** elevate `JobSchedulerService` to saga engine. Do **not** bind P7 to Identity `TenantProvisioningOrchestrator`.

External Temporal: deferred until operational need proven (ADR alternative rejected for reference path).
