## 4. Recommendation

1. Treat first product BB as an **external contract consumer** (even if later co-located).  
2. Ship versioned Product Control Contract (ADR-P7-003) before adapters proliferate.  
3. Use Identity provisioner only as **design reference** for idempotent steps — separate ports for product tenants.  
4. Until a real BB repo is in-workspace, P7.5 gate uses a **reference mock/stub BB** with contract tests — do not fake production support.
