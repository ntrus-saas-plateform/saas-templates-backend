# ADR-018 — Versioned Vertical Workspace Configuration

## Status

Accepted (P0-A lock)

## Context

ERP tenant/org settings use dedicated settings tables and resolvers. Edge verticals need configuration (feature toggles, policy knobs, branding-for-ops, integration endpoints) that can evolve safely.

## Problem

Mutable single-row config without versions makes audit/rollback impossible and complicates multi-tab (stale config vs session).

## Options considered

| Option | Summary |
|--------|---------|
| A | Unversioned JSON blob per vertical |
| B | Reuse ERP `tenant_settings` |
| C | Versioned vertical workspace configuration in Edge CP |

## Decision

**Option C.** Each vertical has **versioned configuration**:

- Immutable versions (append-only) or explicit version numbers.  
- One **active** pointer per vertical.  
- Changes create a new version; activation is an audited action.  
- Workspace session may record `config_version` for conflict detection (optional but recommended with ADR-020).

## Rationale

Supports safe rollout/rollback and audit (ADR-015) without touching ERP settings (constraint 1).

## Security implications

- Only permitted roles activate config.  
- Secrets in config must use secret-store references (pattern from ERP `033_secret_store.sql`), not plaintext if avoidable.  
- Constraint 5: activation server-side.

## Operational implications

Show version history in Edge console; runbook for rollback.

## Data implications

Tables e.g. `edge_vertical_config_versions(vertical_id, version, body, created_by, created_at)` + `active_version`.

## Migration implications

073+; no ERP settings ALTER.

## Rejected alternatives

- **A:** Unversioned — weak audit/rollback.  
- **B:** Tenant settings — wrong domain / requires tenant_id.

## Consequences

- APIs under `/api/v1/edge/verticals/{id}/config…`.  
- Reconcile does not invent config versions (ADR-010).

## Acceptance criteria

- [ ] Updating config creates new version; old readable.  
- [ ] Activate emits audit event.  
- [ ] ERP settings endpoints unchanged.

## Mandatory constraints

1, 5, 6.
