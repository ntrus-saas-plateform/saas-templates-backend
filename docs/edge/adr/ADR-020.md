# ADR-020 — Multi-Tab Workspace Session Behavior

## Status

Accepted (P0-A lock)

## Context

Operators often keep multiple browser tabs open. ERP org switch updates Keycloak and requires token refresh (`POST /platform/organizations/switch`). Edge opaque workspace sessions (ADR-007/008) need explicit multi-tab rules.

## Problem

Per-tab divergent vertical bindings with a shared cookie cause confused writes; silent acceptance of stale tabs causes cross-vertical mutations.

## Options considered

| Option | Summary |
|--------|---------|
| A | Per-tab session cookies (different names) |
| B | Shared cookie but no rotation on switch |
| C | Shared workspace cookie; switch rotates; stale tab gets 401/409 |

## Decision

**Option C.**

| Rule | Behavior |
|------|----------|
| Cookie | **One shared** `okapi_edge_*` workspace session cookie across tabs |
| Vertical switch | **Rotates** session (new id / version); previous id revoked |
| Stale tab | Next API call with old session id or mismatched `config_version` / vertical hint → **401** (unauthenticated/invalid session) or **409** (conflict: workspace changed) |
| UX | Stale tab must re-select vertical / reload; no silent rewrite |

Frontend vertical id remains a selector; server session wins (constraint 5).

## Rationale

Simplest secure model with HttpOnly cookie; matches rotation lifecycle (ADR-008).

## Security implications

- Prevents tab A (vertical X) from acting after user switched to Y in tab B.  
- Constraint 2: ERP tabs/`edge_bff_session` unaffected.  
- Constraint 4: no merge with tenant middleware.

## Operational implications

Client should handle 409 with “workspace changed” toast and refresh bootstrap.

## Data implications

`rotation_version` / session id as in ADR-008; optional echo of active vertical in bootstrap payload.

## Migration implications

None beyond session schema.

## Rejected alternatives

- **A:** Per-tab cookies — complex, easy to mis-proxy.  
- **B:** No rotation — stale tab keeps old vertical with shared cookie ambiguity.

## Consequences

- Edge console bootstrap endpoint returns current vertical + session version.  
- Automated Playwright multi-tab test in P0-G/H.

## Acceptance criteria

- [ ] Switch in tab B invalidates tab A’s in-flight session id.  
- [ ] Stale mutation attempt returns 401 or 409 (documented mapping).  
- [ ] ERP multi-org switch behavior unchanged.

## Mandatory constraints

1, 2, 4, 5.
