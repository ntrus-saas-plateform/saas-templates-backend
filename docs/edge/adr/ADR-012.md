# ADR-012 — MFA in Keycloak; Edge Policy; Step-Up

## Status

Accepted (P0-A lock)

## Context

ERP realm already configures OTP/WebAuthn required actions (`platform-realm.json`). Backend has `MfaEnforcementService`, `StepUpGuard`, and `RequireStepUp` reading ACR/AMR from JWT.

## Problem

Edge Admin is high privilege; password-only access is unacceptable. Embedding MFA in app code duplicates IdP and drifts from ERP security architecture.

## Options considered

| Option | Summary |
|--------|---------|
| A | App-native TOTP store in CP |
| B | Inherit ERP tenant `security.mfaPolicy` |
| C | MFA enforced in `edge-admin` Keycloak; Edge policy layer + step-up for sensitive actions |

## Decision

**Option C.**

1. **Keycloak `edge-admin`** enrolls and verifies MFA (TOTP/WebAuthn as realm policy).  
2. **Edge policy** defines which roles/actions require MFA at login vs step-up.  
3. **Step-up** reuses the ACR/AMR pattern (`StepUpGuard` adapted for Edge issuer), not ERP tenant settings tables.

## Rationale

IdP remains SoT for credentials/MFA (DATA-PLACEMENT rule); Edge adds authorization policy — adapted contract (constraint 6) without sharing tenant MFA settings (constraint 1).

## Security implications

- Break-glass and delegation grant require step-up (ADR-013/014).  
- Constraint 3: step-up URLs use `edge-admin-web` redirects only.

## Operational implications

Realm required-actions documented in Edge runbook; recovery codes process separate from ERP tenants.

## Data implications

Policy document/version in workspace or global Edge config (ADR-018 may version related settings). No MFA secrets in CP.

## Migration implications

None for secrets; optional policy seed in 073+.

## Rejected alternatives

- **A:** App TOTP — duplicates IdP, backup nightmare.  
- **B:** Tenant MFA policy — wrong domain.

## Consequences

- Edge login UX may force CONFIGURE_TOTP via KC.  
- Sensitive Edge routes declare min ACR.

## Acceptance criteria

- [ ] Password-only user blocked when policy requires MFA.  
- [ ] Step-up challenge uses Edge client.  
- [ ] ERP MFA settings paths unchanged.

## Mandatory constraints

1, 2, 3, 6.
