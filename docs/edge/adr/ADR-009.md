# ADR-009 — Edge Data Placement (Control Plane Only, Migrations 073+)

## Status

Accepted (P0-A lock)

## Context

Identity/RBAC for ERP already lives in control-plane Postgres (`docs/DATA-PLACEMENT.md`). Highest CP migration today: `072_drop_industry_permissions.sql`. Tenant DB migrations continue separately (e.g. `076_*`) for ERP domains.

## Problem

Putting Edge Admin SoT in tenant DBs would require a tenant context Edge does not have and would mix operational ERP data with platform-ops state.

## Options considered

| Option | Summary |
|--------|---------|
| A | Edge tables in each tenant database |
| B | Mix Edge columns into existing ERP CP tables |
| C | All Edge tables in Control Plane only; new migrations **073+** |

## Decision

**Option C.** All Edge Admin tables reside in **Control Plane only**. New migrations start at **`migrations/control-plane/073_*.sql`** and onward. Do not alter semantics of 001–072.

## Rationale

Matches existing CP placement for cross-tenant registry concerns; keeps Edge available before any tenant DB exists; constraint 6.

## Security implications

- CP credentials already highly sensitive — Edge secrets/session hashes join that trust tier.  
- RLS/tenant_id patterns in tenant DB are irrelevant; Edge authz is application-enforced.

## Operational implications

- CP backup includes Edge sessions/memberships — define retention.  
- Migrate job must remain ordered; never renumber 072.

## Data implications

Expected domains: verticals, admins, memberships, invitations, workspace sessions, workspace config versions, Edge-specific audit extras if needed.

## Migration implications

- Forward-only 073+.  
- Tenant migrations **out of scope** for Edge Admin SoT.

## Rejected alternatives

- **A:** Tenant DB — requires false tenancy.  
- **B:** Alter ERP tables — regression risk (constraint 1).

## Consequences

- Empty `src/modules/edge` persists data via CP pools only.  
- Document Edge tables in DATA-PLACEMENT follow-up after first migration lands.

## Acceptance criteria

- [ ] No Edge SoT migration under `migrations/tenant/`.  
- [ ] First Edge migration version ≥ `073_`.  
- [ ] CI migrate on fresh + existing CP succeeds without modifying 001–072 checksums.

## Mandatory constraints

1, 6.
