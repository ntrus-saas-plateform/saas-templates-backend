# ADR-008 — Workspace Session Lifecycle

## Status

Accepted (P0-A lock)

## Context

Opaque workspace sessions (ADR-007) need a full lifecycle comparable in rigor to ERP token denylist / iron-session patterns, but independent.

## Problem

Missing rotate/revoke rules leave suspended admins with live vertical access; multi-tab switches desync (ADR-020).

## Options considered

| Option | Summary |
|--------|---------|
| A | Create once; expire only by TTL |
| B | Full lifecycle: create / validate / renew / rotate / revoke; revoke on suspension |
| C | Bind 1:1 to KC refresh token only |

## Decision

**Option B.** Operations:

| Op | Behavior |
|----|----------|
| **Create** | After authn + membership check; bind vertical |
| **Validate** | Every Edge API; check admin state, membership, expiry, revocation |
| **Renew** | Sliding or absolute renew within policy; re-check authz |
| **Rotate** | On vertical switch or privilege change; invalidate prior session id |
| **Revoke** | Logout, suspend (`SUSPENDED`/`DEACTIVATED`), security event, break-glass end |

**Revoke on suspension is mandatory.**

## Rationale

Matches security expectation for admin consoles; supports constraint 2 independence from ERP BFF logout.

## Security implications

- Rotation prevents session fixation across verticals.  
- Validate must hit SoT (or explicitly invalidated cache — ADR-019).  
- Failed validate → 401; vertical mismatch / version skew → 401/409 (ADR-020).

## Operational implications

Metrics: create/renew/revoke/reject rates. Alert on mass revoke.

## Data implications

Session rows: status, `rotated_from`, `expires_at`, `revoked_at`, `rotation_version`.

## Migration implications

Schema in 073+; TTL indexes for GC job.

## Rejected alternatives

- **A:** TTL-only — too weak for suspend.  
- **C:** KC-only — cannot express vertical binding cleanly; couples logout.

## Consequences

- Edge logout ≠ ERP logout.  
- Suspension use case must call session revoke in same transaction as status update when possible.

## Acceptance criteria

- [ ] Tests for each lifecycle op.  
- [ ] Suspend admin → subsequent Edge API 401.  
- [ ] ERP session lifecycle code paths unchanged.

## Mandatory constraints

1, 2, 4, 5.
