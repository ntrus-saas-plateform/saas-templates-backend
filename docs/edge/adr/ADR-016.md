# ADR-016 — Frontend Isolation: `edge-console`, `okapi_edge_*`, Edge Proxies

## Status

Accepted (P0-A lock) — Decision **1A**

## Context

ERP UI lives in `saas-template-frontend` (`edge-frontend`) under `app/(shell)/**` with Org Switcher and BFF cookie `edge_bff_session`. Auth via `/api/auth/*` and `/api/backend/[...path]` against `platform-web`.

## Problem

Building Edge Admin inside `(shell)` would inherit ERP chrome, org switch, and session cookie — guaranteeing constraint violations.

## Options considered

| Option | Summary |
|--------|---------|
| A | Separate Next.js app/deployable |
| B | Pages inside `(shell)` with feature flags |
| **1A** | Isolated `(edge-console)` route group in the existing Next app |

## Decision

**1A:**

| Concern | Choice |
|---------|--------|
| Route group | `app/(edge-console)/**` |
| Chrome | Edge-only layout; **no** Org Switcher / ERP shell |
| Cookies | `okapi_edge_*` only (dedicated iron-session password/secret) |
| Auth BFF | `/api/edge-auth/*` |
| API proxy | `/api/edge-backend/*` → Nest `/api/v1/edge/**` |
| KC client | `edge-admin-web` |

Do **not** rename or reuse `edge_bff_session`.

## Rationale

Same deployable reduces ops cost while enforcing isolation in routing/cookies (constraints 1–2). Locked product decision 1A.

## Security implications

- Separate session secret from `SESSION_SECRET` used by ERP BFF (new env e.g. `EDGE_SESSION_SECRET`).  
- Proxy must not forward Edge cookies to ERP backend routes or vice versa.  
- Constraint 3: PKCE against `edge-admin-web` only.

## Operational implications

One Next deployment; route-based monitoring. CSP/redirect allowlists include Edge paths.

## Data implications

No FE persistence of vertical authority beyond cookie session id.

## Migration implications

Additive routes only; `(shell)` untouched.

## Rejected alternatives

- **A:** Second app — deferred; higher ops cost for P0.  
- **B:** Shared shell — rejected by 1A / constraint 4.

## Consequences

- Deep links for invitations target Edge console.  
- Developers must not import Org Switcher into Edge layout.

## Acceptance criteria

- [ ] `(edge-console)` renders without Org Switcher.  
- [ ] Cookie names verified `okapi_edge_*`; `edge_bff_session` still used by ERP.  
- [ ] `/api/edge-auth/*` and `/api/edge-backend/*` exist; ERP `/api/auth/*` unchanged.

## Mandatory constraints
