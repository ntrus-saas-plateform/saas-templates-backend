# ADR-015 — Extend Existing Audit Writer; Edge Event Taxonomy

## Status

Accepted (P0-A lock)

## Context

ERP uses `AUDIT_WRITER_PORT` / `PgAuditWriter` / `AuditInterceptor` / `@AuditAction`. Platform-admin has a dedicated `platform_admin_audit_log` for tenant provision actions.

## Problem

A second ad-hoc logger for Edge would diverge schemas and lose correlation; overloading `platform_admin_audit_log` would confuse ERP compliance queries.

## Options considered

| Option | Summary |
|--------|---------|
| A | New standalone Edge audit microservice |
| B | Write Edge events into `platform_admin_audit_log` |
| C | Extend existing audit writer; add Edge event taxonomy |

## Decision

**Option C.** Reuse **`PgAuditWriter` / `@AuditAction` pipeline** (adapted contract). Introduce an **Edge event taxonomy** (namespaced actions, e.g. `edge.admin.suspend`, `edge.workspace.switch`, `edge.invitation.accept`, `edge.break_glass.grant`). Do not overload platform-admin audit table for vertical ops.

## Rationale

One writer, clear event names — constraint 6 without regression to ERP queries (constraint 1).

## Security implications

- Tamper-evident retention inherits ERP audit store controls.  
- Must capture actor, vertical id, workspace session id, request id.  
- Failures to write audit on sensitive mutations should fail the request or compensate per ERP precedent.

## Operational implications

Dashboards filter `edge.*` actions; SIEM rules updated.

## Data implications

If current audit table lacks columns for `vertical_id`, prefer nullable additive columns or metadata JSON — additive only, non-breaking.

## Migration implications

Optional additive migration 073+; never drop ERP audit columns.

## Rejected alternatives

- **A:** Extra system — ops cost.  
- **B:** Wrong table semantics.

## Consequences

- Controllers under `/api/v1/edge/**` annotate `@AuditAction` with Edge names.  
- Taxonomy list versioned in docs/edge (extend as features land).

## Acceptance criteria

- [ ] Sample Edge mutations produce `edge.*` audit rows.  
- [ ] ERP `@AuditAction` events still queryable as before.  
- [ ] No Edge writes to `platform_admin_audit_log` for vertical ops.

## Mandatory constraints

1, 6.
